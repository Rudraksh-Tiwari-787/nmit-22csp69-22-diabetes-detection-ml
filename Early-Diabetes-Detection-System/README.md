\# Early Diabetes Detection Using Machine Learning Models



\## Project Overview

This project predicts diabetes risk using machine learning algorithms and healthcare parameters from the PIMA Indians Diabetes Dataset.



\## Features

\- User health parameter input

\- Real-time diabetes prediction

\- Machine learning based diagnosis

\- Web-based prototype



\## Technologies Used

\- Python

\- Flask

\- Scikit-learn

\- Pandas

\- NumPy

\- HTML/CSS



\## Machine Learning Algorithm

\- Random Forest Classifier



\## Dataset

PIMA Indians Diabetes Dataset



\## Functional Requirement Implemented

The system allows users to enter health parameters and predict whether the patient is diabetic or non-diabetic.



\## How to Run



\### Install Requirements

pip install -r requirements.txt



\### Train Model

python train\_model.py



\### Run Application

python app.py



\### Open Browser

http://127.0.0.1:5000
